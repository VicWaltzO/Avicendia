# Avicendia

Proyecto de SaaS avícola para registrar y consultar información productiva de distintas empresas con trazabilidad y control de acceso.

## Estado del proyecto

Preparación del repositorio. Todavía no hay una aplicación ejecutable, servicios desplegados ni integraciones verificadas. La captura automatizada, IA, analítica e IoT forman parte de la visión futura y no son capacidades disponibles.

## Trabajo por tareas

- Rama principal: `main`.
- Identificadores: `CG-###`, independientes del número de issue de GitHub.
- Cada incremento se desarrolla en una rama individual `codex/CG-###-descripcion`.
- Cada entrega incluye commits identificables, verificaciones proporcionales y un resumen de resultados.
- Una tarea se cierra al cumplir su aceptación y revisión; no basta con que compile.

## Documentación de ingeniería

El paquete especializado Control Granja Engineering v2.1 y el roadmap original se conservan en el entorno local de ingeniería. No se requieren para consultar esta base pública y no forman parte de esta entrega. Antes de publicar una versión de esos materiales se revisarán su contenido, referencias e historial.

No hay instalación de dependencias ni pruebas de aplicación que ejecutar en esta fase. La verificación de CG-001 consiste en revisar un clon limpio, su árbol, sus enlaces y el historial alcanzable de su rama.
